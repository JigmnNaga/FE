## 📱 지금나가 Frontend

약속을 생성하고 참여자들의 이동 상황과
도착 예정 시간(ETA)을 실시간으로 확인할 수 있는
지금나가의 프론트엔드 애플리케이션입니다.

사용자가 약속을 설정하고,
약속 장소와 참여자의 위치를 확인하며,
이동 중인 친구들의 현재 위치와 도착 예정 시간을
한눈에 확인할 수 있도록 사용자 화면을 구현합니다.

---

## 주요 기능

- 약속 생성 및 참여
- 약속 시간 및 장소 확인
- 참여자 위치 확인
- 최적 약속 장소 확인
- 이동 경로 및 도착 예정 시간(ETA) 확인
- 출발 후 실시간 위치 공유
- 친구들의 이동 상태 확인
- 약속 진행 상태 확인

---

## 역할

Frontend는 다음 기능을 담당합니다.

- 사용자 화면 및 UI 구현
- 약속 생성 및 관리 화면 구현
- 약속 장소 및 지도 화면 구현
- 참여자 위치 및 이동 상태 시각화
- 실시간 위치 및 ETA 정보 표시
- Backend API 연동
- 사용자 입력 및 상태 관리
- 사용자 경험(UX) 개선
